# 🍱 Smart Food Planner

A full-stack food planning and inventory management system built using React, Node.js, Express.js, and MySQL.

## 🚀 Features

- 🏠 Dashboard
- 🧮 Food Calculator
- 🍽️ Menu Management
- 📦 Inventory Management
- 📅 Meal Schedule
- 📋 Food Plan History
- 🥘 Ingredient Calculation
- 💾 Save Food Plans
- 📦 Deduct Ingredients from Inventory
- ⚠️ Low Stock Detection

## 🛠️ Technologies Used

### Frontend

- React
- JavaScript
- HTML
- CSS
- Vite

### Backend

- Node.js
- Express.js
- MySQL2
- CORS
- dotenv

### Database

- MySQL 8.0
